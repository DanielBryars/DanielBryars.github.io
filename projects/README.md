# Projects

This is the active project section of the site.

| Path | What it is |
| --- | --- |
| `index.html` | The projects landing page, served at `/projects/` |
| `<project>/index.html` | The project write-up |
| `<project>/images/` | Original still images for that project |
| `<project>/videos/` | Original video clips for that project |
| `<project>/files/` | PDFs, SVGs and other supporting source files |
| `<project>/media/` | Generated web-sized images, posters and MP4 clips |

Edit the HTML and the source files in `images/`, `videos/` and `files/`.
Do not edit `media/` by hand; regenerate it with the media tools.

MSc module pages live under `msc-ai/<module>/index.html` and share the
programme-level `msc-ai/images/` and `msc-ai/media/` folders.
